# Lambda OS privacy policy

Lambda OS is an internal Chrome extension for employees of Lambda, Inc. It shows Data Center Operations information
from the user's own work apps on the browser's new-tab page.

## What it reads

With the user's existing browser sign-ins, and only what that user can already see: NetBox, Jira, Slack, Gmail,
Google Calendar, NetSuite, Atium, Grafana and Yard Central. Each app can be turned off in Settings → Sources.

## Where data is kept

Only in the user's own browser (Chrome extension storage), to show the dashboard and open new tabs quickly. Lambda OS
has no server: nothing is sent to Lambda, the developer, or anyone else. No passwords, API keys or sign-in tokens are
stored. Removing the extension deletes its data.

## Ask AI

If the user asks a question in Ask AI, the question and the relevant dashboard data are sent to the AI chat the user
picked (Claude, ChatGPT or Gemini) under the user's own account. Before sending, people's names, email addresses,
IP/MAC addresses, serial numbers and money amounts are replaced with placeholders by default (Settings → Privacy); they
are put back only on the user's screen. Lambda OS uses the chat's temporary mode where available, or removes the chat
it created after the answer. Settings → Privacy → "Never send to an AI" turns this off completely.

## Sharing

Data is not sold, shared or used for advertising, and not used for anything other than showing the user their own
dashboard.
